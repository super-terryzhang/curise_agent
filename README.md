# Curise Agent

邮轮供应链业务系统的当前 v3 源码。仓库包含订单与 PO 自动化、供船安排、产品主数据、价格期间、批量上传、询价单生成和工作台等模块。

## 目录

- `v3_backend/`：FastAPI、SQLAlchemy、Alembic、任务与领域逻辑。
- `v3-frontend/`：Next.js 前端。
- `PROGRESS.md`：当前生产基线、本地完成内容及尚未部署事项。

## 本地启动

后端环境变量以 `v3_backend/.env.example` 为起点；前端环境变量需在本地自行建立，禁止提交真实密钥。具体依赖和命令分别见两个子项目的配置文件及后端 README。

## 数据安全

本仓库为公开仓库，不包含真实 PO/PDF、用户上传文件、本地数据库、生成的询价文件、环境变量或生产部署证据。真实业务测试资料必须通过受控私有渠道提供，不得加入 Git。

## 发布边界

提交到 GitHub 不等于部署生产。生产发布必须单独执行迁移、后端发布、前端发布与正式环境核验，并更新进度记录。
